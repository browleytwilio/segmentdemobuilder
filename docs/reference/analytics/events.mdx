# Analytics Event Reference

The Segment Demo Builder tracks 55 events across 9 categories via Segment's analytics.js SDK. Every event is compile-time checked against the `SegmentEventMap` TypeScript interface — typos and missing properties cause build errors.

## Auth Events

<AccordionGroup>
  <Accordion title="Signed Up">
    Fired when a user creates a new account via email/password.

    | Property | Type | Description |
    |----------|------|-------------|
    | `method` | `"email"` | Always `"email"` |
  </Accordion>

  <Accordion title="Signed In">
    Fired on successful login.

    | Property | Type | Description |
    |----------|------|-------------|
    | `method` | `"email" \| "magic_link" \| "oauth"` | Authentication method |
    | `provider` | string (optional) | OAuth provider name (e.g., `"google"`, `"github"`) |
  </Accordion>

  <Accordion title="Magic Link Requested">
    Fired when a user requests a magic link login email.

    | Property | Type | Description |
    |----------|------|-------------|
    | `email_domain` | string | Domain portion of the email (e.g., `"twilio.com"`) |
  </Accordion>

  <Accordion title="OAuth Started">
    Fired when a user initiates OAuth login.

    | Property | Type | Description |
    |----------|------|-------------|
    | `provider` | string | OAuth provider (`"google"` or `"github"`) |
  </Accordion>

  <Accordion title="Auth Callback Completed">
    Fired after a successful OAuth callback.

    | Property | Type | Description |
    |----------|------|-------------|
    | `method` | `"oauth"` | Always `"oauth"` |
  </Accordion>

  <Accordion title="Signed Out">
    Fired on manual sign-out.

    | Property | Type | Description |
    |----------|------|-------------|
    | `method` | `"manual"` | Always `"manual"` |
  </Accordion>

  <Accordion title="Sign Up Failed">
    | Property | Type | Description |
    |----------|------|-------------|
    | `method` | `"email"` | Always `"email"` |
    | `error` | string | Error message |
  </Accordion>

  <Accordion title="Sign In Failed">
    | Property | Type | Description |
    |----------|------|-------------|
    | `method` | `"email" \| "magic_link" \| "oauth"` | Authentication method |
    | `error` | string | Error message |
    | `provider` | string (optional) | OAuth provider name |
  </Accordion>

  <Accordion title="Magic Link Failed">
    | Property | Type | Description |
    |----------|------|-------------|
    | `error` | string | Error message |
  </Accordion>

  <Accordion title="OAuth Failed">
    | Property | Type | Description |
    |----------|------|-------------|
    | `provider` | string | OAuth provider |
    | `error` | string | Error message |
  </Accordion>

  <Accordion title="Auth Callback Failed">
    | Property | Type | Description |
    |----------|------|-------------|
    | `error` | string | Error message |
  </Accordion>
</AccordionGroup>

## Builder Wizard Events

<AccordionGroup>
  <Accordion title="Wizard Started">
    Fired when the builder wizard page loads.

    | Property | Type | Description |
    |----------|------|-------------|
    | `has_persisted_state` | boolean | Whether the Zustand store had saved wizard state |
  </Accordion>

  <Accordion title="Wizard Step Navigated">
    Fired on every step transition (forward or backward).

    | Property | Type | Description |
    |----------|------|-------------|
    | `from` | number | Previous step number |
    | `to` | number | New step number |
    | `direction` | `"forward" \| "backward"` | Navigation direction |
    | `time_on_step_ms` | number (optional) | Milliseconds spent on the previous step |
  </Accordion>

  <Accordion title="Wizard Step Submitted">
    Fired when a wizard step passes validation. Properties differ by step:

    **Step 1 (Context):**
    | Property | Type |
    |----------|------|
    | `step` | `1` |
    | `customer_name_length` | number |
    | `persona` | string |
    | `industry` | string |

    **Step 2 (Architecture):**
    | Property | Type |
    |----------|------|
    | `step` | `2` |
    | `enable_se_sidebar` | boolean |
    | `enable_seeded_profiles` | boolean |
    | `enable_profile_api` | boolean |
    | `enable_intent_predictions` | boolean |

    **Step 3 (Scenarios):**
    | Property | Type |
    |----------|------|
    | `step` | `3` |
    | `scenario_count` | number |
    | `industry` | string |

    **Step 4 (Credentials):**
    | Property | Type |
    |----------|------|
    | `step` | `4` |
    | `fields_provided_count` | number |
  </Accordion>

  <Accordion title="Credentials Help Opened">
    Fired when the credentials help section is expanded. No properties.
  </Accordion>

  <Accordion title="Playbook Created">
    | Property | Type | Description |
    |----------|------|-------------|
    | `playbook_id` | string | New playbook UUID |
  </Accordion>

  <Accordion title="Playbook Creation Failed">
    | Property | Type | Description |
    |----------|------|-------------|
    | `error` | string | Error message |
  </Accordion>
</AccordionGroup>
