The AI Copilot is a slide-out chat panel available on every authenticated page. It understands Segment CDP concepts and is aware of your current playbook context.

## Opening the Copilot

Click the sparkle button in the bottom-right corner of any app page. The panel slides in from the right.

## What It Knows

The Copilot has access to a built-in **Segment Knowledge Tool** that provides detailed information on:

- Identity Resolution & Unify
- Profile API
- Protocols & Tracking Plans
- Sources & Destinations
- Engage & Audiences
- Functions
- Computed Traits
- Data Warehouses
- Privacy & Compliance

When you ask about a Segment concept, the Copilot automatically looks it up in its knowledge base and uses the result to give you an accurate, detailed answer.

## Playbook Context

When you're working in the Builder Wizard, the Copilot receives your current configuration as context:

- **Customer name** and **industry**
- **Persona** (CMO, CTO, Product Manager, Data Team)
- **Architecture flags** (sidebar, seeded profiles, Profile API, etc.)
- **Selected scenarios**

This means you can ask questions like:
- *"What Segment features should I emphasize for a CTO?"*
- *"How does identity resolution help in FinTech?"*
- *"Why would I enable the Profile API for this demo?"*

## Usage Tips

<Tip>
The Copilot streams responses in real-time. You can stop generation at any time by clicking the stop button.
</Tip>

- Ask specific questions about Segment features to get grounded answers
- Use it during the Builder Wizard to get advice on scenario selection
- The Copilot remembers the conversation within a session, so you can have multi-turn discussions

## Rate Limits

The Copilot is rate-limited to **30 requests per minute** per user to prevent abuse. If you hit the limit, wait a moment and try again.
